首次将安全版视觉工作流打包为 `why-ping` 市场的独立 Codex 插件，开发者为 Why.Ping。

- 中文化技能说明、界面名称、默认提示、评审规程、Blender 预检和安全文档。

- 补充 loopback 预览、浏览器外网、构建副作用、敏感信息、路径链接和中断预算边界。
- 不新增 hooks、MCP、安装器、守护进程或外部 API 配置；明确行为规则不等于系统沙箱。
- 提供零 npm 依赖的静态结构测试、跨平台 CI 定义与隔离安装/行为验收清单。
- 保留上游 MIT 版权及来源信息，不复制上游预览素材。
