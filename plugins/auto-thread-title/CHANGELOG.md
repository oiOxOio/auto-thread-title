# 更新记录

正式版本使用 `MAJOR.MINOR.PATCH`。修复递增 PATCH，新增兼容功能递增 MINOR；时间戳缓存后缀仅用于可选的本地开发迭代。

## 0.2.1

- 自动钩子在本机预读当前任务的必要元数据，核对 ID、目录和创建时间，并计算上海时区日期；标题格式已合规时不再注入命名指令。
- 正常路径使用简短指令，模型仅需写入当前任务标题一次，减少一次模型侧读取工具往返；可在同批工具调用中先改名再开展业务操作。
- 本地预读使用 `thread/read`、`includeTurns: false`，不请求历史回合，不使用或注入任务正文、`preview`；不新增 MCP 服务或模型任务。
- 接口不可用或启动瞬间任务暂不可读时回退完整核验指令；身份或目录不匹配时跳过。保留提前命名、自动范围、固定标题格式和最多一次写入的边界。

本次减少注入指令和正常路径的模型工具往返，不承诺固定额度降幅。首次 startup 的任务可读性及真实桌面改名仍需在对应环境验收；更新不会补触发已有任务。

## 0.2.0

- 自动标题在首条请求主题明确后，优先于业务工具调用完成，不再等到最终答复。仍只处理当前任务、最多一次，不增加模型回合；主题不明或命名工具不可用时跳过。
- 默认范围自动跟随本机 Codex 保存的项目，新增、移除和迁移项目会在下一次新任务启动时更新，支持 Git linked worktree。Windows、macOS、Linux 各自读取本机项目，无需维护跨系统路径映射。
- 增加 `doctor --projects`，只读核对项目范围和当前目录匹配。优先使用桌面端维护的 CLI；读取项目列表失败时跳过，不扩大范围。
- 正式发布改用清晰的 `0.2.0` 版本号，后续修复和功能按语义化版本递增。

升级保留已有手动目录和停用状态。需要切换为自动跟随项目时，使用配置技能或平台启动器执行 `configure --scope projects --enable`；首次钩子信任仍由 Codex 管理。更新后新建任务验证，已有任务不会补触发。

提前命名不能保证任意中断时点都已完成写入。改名前中断仍可能保留原名，插件不会自动恢复中断任务。
